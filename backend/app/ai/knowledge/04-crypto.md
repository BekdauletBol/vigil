# Операции с виртуальными активами (VASP)

Переводы на криптобиржи и обменники используются для обналичивания и пересечения границ без традиционных банковских каналов.

## Признаки
- Регулярные пополнения криптобиржи с последующим отсутствием обратных зачислений.
- Пополнение с карт третьих лиц, P2P-операции с большим числом разных контрагентов.
- Суммы, не соответствующие доходам клиента.
- Взаимодействие с обменниками без лицензии.

## Что проверить аналитику
- Лицензирован ли провайдер услуг виртуальных активов.
- Профиль клиента: доход, род занятий, возраст счёта.
- Связь с другими кейсами по тем же получателям.

## Рекомендуемые действия
Запросить пояснения клиента об источнике средств; при отсутствии обоснования — эскалация.
